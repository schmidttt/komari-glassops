# Komari GlassOps v1.0.8

`v1.0.8` 重点完善 Komari 1.4.3 兼容性，并优化 CPU 与 Ping 历史数据的读取稳定性和请求效率。

## 本次更新

- **适配 Komari 1.4.3 后台**：更新主题内嵌管理后台；仅在后端版本精确匹配时启用，其他版本自动进入 Komari 官方后台，避免误用不兼容页面。
- **修复 CPU 历史缺失**：新版指标没有返回 CPU 历史时，负载图会自动从兼容记录补齐，同时保留已经取得的其他指标。
- **统一 Ping 任务顺序**：详情页 Ping 卡片遵循后台任务顺序，浏览和配置结果保持一致。
- **减少首页 Ping 请求**：同一时间范围内的可见节点改为批量读取历史数据，大量节点时减少重复请求；批量数据不完整时仍会自动逐节点回退。
- **加强异常保护**：离开首页后丢弃迟到的批量结果，避免无效更新和额外旧接口请求。
- **补充回归验证**：新增后台版本门控、CPU 历史回退、Ping 排序、批量请求及回退路径测试。

## 安装

1. 下载 Release 附件中的 `komari-glassops-v1.0.8-build-*.zip`。
2. 登录 Komari 后台，进入主题管理并导入 ZIP。
3. 启用 `Komari GlassOps`，建议检查首页节点 Ping、详情负载图和后台入口。

请勿上传 GitHub 自动生成的 Source code 压缩包；它不是 Komari 可直接导入的主题包。

## 验证边界

发布包使用完全虚构的固定节点数据完成类型检查、代码规范、生产构建、ZIP 结构和浏览器组合回归。真实 Komari 上传启用、Safari、不同 GPU 和长期运行仍建议独立验证。
