# Komari GlassOps v1.1.0

## 本次更新

- 首页「节点对比」新增「线路对比」。选择 2–4 台节点，用同一探测任务和时间范围比较延迟曲线、丢包时间、P50／P99 和样本数。手机支持点击查看时间条，桌面支持鼠标和键盘。
- Ping 详情区分最新丢包、历史成功和缺少采样。长周期网络速率显示后端实际返回的聚合口径。
- 节点列表支持按 CPU、内存、磁盘和流量配额使用率排序。

## 兼容与安装

从 Release 下载对应主题 ZIP，在 Komari 后台导入并启用。Komari 1.6.2 使用官方后台，已登记的 1.4.3、1.5.0-fix1、1.6.0 各自选择对应的内嵌后台。旧核心缺少 Metric 方法时，比较页可使用支持的逐节点 Ping 记录。统计样本不齐全时显示缺省状态。

兼容检查覆盖旧版 ZIP 升级设置、真实 1.6.2 公开监控与 Ping 样本、旧后台入口回退、访客权限和移动布局。
