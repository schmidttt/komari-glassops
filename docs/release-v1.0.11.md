# Komari GlassOps v1.0.11

`v1.0.11` 适配 Komari 1.6.0 的管理后台，同时保留 1.4.3 与 1.5.0-fix1 后台，可先更新主题再升级后端。

## 本次更新

- 新增固定来源的 Komari 1.6.0 内嵌后台，支持新版通知渠道、登录入口和终端工作区；不再包含上游已移除的剪贴板、负载告警、全局终端设置和旧消息发送器入口。
- 按后端精确版本选择三套后台。其他版本、查询失败或超时继续回退官方后台；直接打开旧书签也会在加载应用前校验版本。
- 修正访客审计提示：1.6.0 移除该能力后不发起访客事件请求，管理员操作日志继续可用；旧核心提供该能力时仍保留采集开关。
- 新后台保存主题设置时合并最新完整配置，保留首页 Ping 等额外设置。公开首页、详情、实时监控、历史统计和默认 compact 卡片保持原有行为。

## 安装与回退

1. 下载本 Release 的 `komari-glassops-v1.0.11-build-*.zip`，在 Komari 主题管理中导入并启用。
2. 点击首页“后台管理”：Komari 1.4.3、1.5.0-fix1、1.6.0 分别使用匹配的内嵌后台，其余版本使用官方后台。
3. 检查主题设置、节点详情和历史图表；1.6.0 用户可在通知渠道页面检查迁移后的配置。

不要上传 GitHub 自动生成的 Source code 包。回退主题可重新导入 v1.0.10；在 Komari 1.6.0 上将使用官方后台。回退主题不会回退后端数据库或恢复后端已移除的功能。

## 升级边界

本主题不会升级后端或 Agent。Komari 1.6.0 将通知改为渠道注册机制，旧通知配置可能需要安装对应插件并重新配置。官方发布说明对 JavaScript 渠道存在前后不一致描述；本次按最终标签源码和真实运行结果确认内置 Webhook 与 JavaScript 渠道均存在。
