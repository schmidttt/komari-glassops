# Komari GlassOps v1.0.9

`v1.0.9` 优化长时间范围历史图表的聚合信息展示，避免把 UTC 日统计桶误读为每天只在北京时间 `08:00` 采样一次。

## 本次更新

- **明确聚合粒度**：使用服务端降采样数据时，显示分钟、小时或日聚合，并说明每个点代表对应统计区间的平均值。
- **修正日桶时间表达**：日聚合横轴显示统计桶日期，tooltip 标题明确标注“日聚合”，不再把 UTC `00:00` 桶起点显示成误导性的本地 `08:00`。
- **同步负载历史图**：LoadChart 同样解释服务端聚合元数据，并分别处理普通负载历史和独立 Ping 序列，避免兼容记录回退被错误标记。
- **保持数据语义不变**：不修改后端返回值、聚合算法、查询点数或自定义时间范围边界。
- **补充回归验证**：新增 24 小时间隔和 UTC 日桶场景，完整 Chromium Playwright 回归扩展到 100 项。

## 安装

1. 下载 Release 附件中的 `komari-glassops-v1.0.9-build-*.zip`。
2. 登录 Komari 后台，进入主题管理并导入 ZIP。
3. 启用 `Komari GlassOps`，建议检查详情页 90 天和自定义跨月范围的聚合提示、横轴日期与 tooltip。

请勿上传 GitHub 自动生成的 Source code 压缩包；它不是 Komari 可直接导入的主题包。

发布包使用完全虚构的固定节点数据完成类型检查、代码规范、生产构建、ZIP 结构和 100 项浏览器回归。真实 Komari 上传启用、真实历史数据、Safari、不同 GPU 和长期运行仍建议独立验证。
